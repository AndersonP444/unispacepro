REQUISITOS PREVIOS EN LA PC DE TUS COLEGAS:
1. XAMPP (o Laragon) instalado con PHP 8.2 o superior y MySQL.
2. Composer instalado (https://getcomposer.org/).
3. WinRAR para descomprimir el archivo.

------------------------------------------------------------------------
PASO 1: DESCOMPRIMIR EL PROYECTO
------------------------------------------------------------------------
1. Crea una carpeta llamada "UnispacePro_Proyecto" en el Escritorio (o donde prefieras).
2. Extrae todo el contenido de "UnispacePro_Proyecto.rar" dentro de esa carpeta.

------------------------------------------------------------------------
PASO 2: ENCENDER E IMPORTAR LA BASE DE DATOS (XAMPP)
------------------------------------------------------------------------
1. Abre el Panel de Control de XAMPP.
2. Enciende "Apache" y "MySQL" pulsando el boton "Start" en ambos.
3. Abre en tu navegador: http://localhost/phpmyadmin
4. En el menu izquierdo, haz clic en "Nueva" (New) y crea una base de datos llamada exactamente:
   unispacepro
5. Selecciona la base de datos "unispacepro" recien creada y haz clic arriba en la pestana "Importar".
6. Haz clic en "Seleccionar archivo" y busca dentro de la carpeta del proyecto el archivo:
   database/unispacepro_actualizado.sql
7. Baja hasta el final de la pagina y haz clic en "Importar" (o "Continuar").
   (Esto cargara automaticamente todas las tablas, el usuario Administrador, profesores, estudiantes, cursos, talleres, salones, el Auditorio Principal con sus 96 butacas y los eventos pagos).

------------------------------------------------------------------------
PASO 3: INSTALAR DEPENDENCIAS DE LARAVEL
------------------------------------------------------------------------
1. Abre la carpeta del proyecto en Visual Studio Code (o abre una terminal PowerShell / CMD dentro de la carpeta).
2. Ejecuta el siguiente comando para instalar la carpeta vendor de Laravel:
   composer install

3. (Opcional) Si deseas regenerar el enlace de almacenamiento de imagenes, ejecuta:
   php artisan storage:link

------------------------------------------------------------------------
PASO 4: ENCENDER LA PAGINA WEB
------------------------------------------------------------------------
En la terminal dentro de la carpeta del proyecto, ejecuta cualquiera de estos dos comandos:

Opcion 1 (Recomendada y mas rapida):
   php -S 127.0.0.1:8000 -t public

Opcion 2 (Comando estandar de Laravel):
   php artisan serve

Finalmente, abre en tu navegador:
   http://127.0.0.1:8000

COMO PROBAR EL AUDITORIO Y LA PASARELA DE PAGO MOVIL / WHATSAPP:
------------------------------------------------------------------------
1. Inicia sesion como Estudiante (ej. Cedula: 28100001 / Clave: Est1234!).
2. Entra en el menu superior a "Auditorio y Eventos" (/auditorio).
3. Elige cualquiera de los eventos especiales (Graduacion, Congreso o Simposio) y haz clic en "Seleccionar Butaca en el Mapa".
4. Haz clic sobre una de las 96 butacas disponibles (A1 a H12).
5. Veras dos opciones:
   - Via 1 (Pasarela Web): Ingresa el Banco Emisor, Telefono y Numero de Referencia del Pago Movil y pulsa "Enviar Solicitud de Reserva". La butaca quedara separada en color ambar ("En Verificacion").
   - Via 2 (Chatbot WhatsApp): Pulsa el boton de WhatsApp para enviar los datos prellenados de la butaca y el Pago Movil al Administrador.
6. Ahora inicia sesion como Administrador (Cedula: 00000001 / Clave: Admin1234!) y entra a "Mi Portal" (/dashboard):
   - En la pestana "Auditorio: Pagos y Asignacion Manual", veras la solicitud pendiente con su numero de referencia para darle a "Aprobar y Enviar QR", o bien el formulario para asignar manualmente la butaca reportada por WhatsApp.
